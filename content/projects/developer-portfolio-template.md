## Project Overview

This project was built to establish a gold-standard portfolio website for software engineers, engineering managers, and technical consultants who need to convey credibility, technical excellence, and clean design.

### Features & Capabilities

- **Separation of Concerns**: Projects, articles, and skills are stored strictly in Markdown and typed configuration files.
- **Flawless Lighthouse Scores**: Scored 100/100 across Performance, Accessibility, Best Practices, and SEO.
- **Zero-Config Deployment**: Built ready for Vercel, Netlify, or static S3/Cloudflare hosting out of the box.
